# Prizify

**Find your frequency.** An original, responsive music discovery app with a midnight-and-coral identity, illustrated covers, and 12 locally playable original instrumental recordings.

[Live demo](https://dnubz.github.io/prizify/) · [GitHub repository](https://github.com/dnubz/prizify)

## Run locally

Requires Node.js 20.11 or later. There are no runtime dependencies or API keys.

```sh
npm start
```

Open `http://localhost:4173`. Use `PORT` to select another port.

```sh
npm test       # meaningful store, search, escaping, and reorder checks
npm run build # verify the ready-to-deploy static distribution
```

Deploy the **`dist/`** folder to any static host. Hash-based routing works on GitHub Pages, including repository subpaths, without rewrite rules. The build is already included; no bundler or installation step is needed.

## What works

- **Home:** featured mixes, mood filters, recommended albums ranked from your likes and recent listening, and recently played tracks.
- **Search:** songs, artists, albums, playlists, genres, and moods, with entity filters and helpful empty states.
- **Library:** liked songs, saved albums, followed artists, and editable playlists.
- **Playlists:** create, rename, describe, delete, add/remove tracks, drag to reorder, or use accessible arrow controls.
- **Player:** actual local audio playback, pause, next/previous, seek, volume, mute, shuffle, repeat one, and repeat queue.
- **Queue:** add, play next, select, remove, clear, drag, and reorder using buttons.
- **Mobile:** bottom navigation, compact player, and expanded artwork view with the complete playback controls. Tap the player artwork to expand.
- **Persistence:** library, recent listening, queue, player modes, and volume are saved to localStorage. Profile includes library export/import.
- **Accessibility:** semantic controls, screen reader labels, pressed states, focus indicators, skip link, native modal dialogs, keyboard shortcuts, and reduced-motion support.

**Keyboard:** Space play/pause, left/right seek five seconds, M mute, / focus search, Escape close. Shortcuts avoid text fields and focused interactive controls.

## Demo music and artwork

The song titles, artists, and releases are fictional. All 12 WAV files are original algorithmic synth compositions created for this project; no commercial recordings, samples, music APIs, or Spotify assets are used. Real audio plays from the same origin, with no external media dependencies. The interface clearly identifies the demo recordings.

Cover illustrations, the hero scene, and the Prizify mark are original SVG assets generated by `scripts/generate-assets.mjs`. Regenerate audio with Python and NumPy using `python scripts/generate-audio.py`. The generated music and artwork are included under the project MIT license. DM Sans and Manrope are bundled locally under their accompanying SIL Open Font Licenses in `dist/assets/`.

## Browser verification

`scripts/verify-browser.mjs` exercises real playback, seeking, volume, search filters, playlist CRUD and persistence, queue reorder/removal, saving albums, and responsive mobile behavior. Install Playwright separately with `npm install --no-save playwright` and its browser with `npx playwright install chromium`, then run:

```sh
node scripts/verify-browser.mjs
```

Use `PRIZIFY_BROWSER_CHANNEL=msedge` or `chrome` for an installed browser. `PRIZIFY_TEST_URL` changes the target. Screenshots go into ignored `test-results/`.

## Scope

This is a complete browser-local demo, not a licensed commercial streaming service. It does not provide authentication, payments, uploads, a backend catalog, or cross-device account synchronization. Library export/import supports manually moving your collection between browsers. A production service would require licensed media, backend storage, and authentication.

